# 操作说明（借款人端 + 管理端）

本说明以 Mock 环境为示例。真实后端就绪后操作步骤一致，仅需把代理地址改到后端。

启动：`npm run mock`（后端） + `npm run dev`（前端）→ 打开 http://127.0.0.1:5173

---

## 一、借款人端

### 1. 注册与登录（U01）

1. 打开首页，自动跳转 `/login`。
2. 点「注册新账号」→ 填账号、手机号（可虚构）、密码（≥8 位）、确认密码。
3. 点「获取验证码」，演示环境固定为 `888888`，填入后提交。
4. 注册成功回登录页。用新账号登录，或直接用演示账号 `demo_user / demo1234`。

**要点**
- 账号、手机号唯一，重复注册返回 409。
- 登录失败不回显密码；账号冻结时提示「账号可能已冻结」。
- 已登录状态访问 `/login` 会自动回到产品页。

### 2. 模拟实名（U02）

1. 左侧进入「资料与实名」。
2. 页面明确标注**非真实身份核验**，仅做格式检查。
3. 填写姓名、18 位虚构证件号。
4. 点「选择图片」上传 JPEG/PNG（≤5 MiB）→ 得到 `file_id`。
5. 点「提交模拟实名」→ 状态变为「已模拟实名」。

**要点**
- 先上传再提交，缺图片会被拒绝。
- 证件号不是 18 位直接提示。
- 未实名用户去申请会被前端拦截并引导到本页。

模拟卡（可选）：填 16–19 位卡号绑定，默认卡只有一张。**不参与任何资金划转**。

### 3. 产品与试算（U03）

1. 进入「贷款产品」，三个产品分别为等额本息 / 等额本金 / 先息后本。
2. 点卡片选中产品，调整金额与期数。
3. 点「开始试算」→ 展示总利息、本息合计、还款方式、预计首期到期日，以及逐期计划表。
4. 点「去申请」带入当前金额期数。

**要点**
- 试算结果全部来自后端，前端不做计算。
- 页面注明「实际到期日以放款后生成的还款计划为准」。

### 4. 提交申请（U04）

1. 「我的申请」→「发起借款申请」。
2. 选产品、金额、期数、用途（可选，≤200 字）→ 提交。
3. 跳转申请详情，状态为**待审核**。

**要点**
- 同一用户最多一笔待审核申请，第二笔返回 409。
- 提交按钮在请求中禁用；网络超时会提示「结果未知」，此时**不要换内容重复点**，先到列表确认是否已生成。

### 5. 撤销与签约（U04）

**撤销**：仅「待审核」显示「撤销申请」，二次确认后状态变「已撤销」。

**签约**：审批通过后状态为「待签约」，详情页显示
- 签约截止时刻（北京时间，`YYYY-MM-DD HH:mm`）
- 实时倒计时（**仅展示**，服务端 72 小时判断为准）

点「确认签约」→ 二次确认规则快照 → 状态变「待放款」。

**要点**
- 超时后页面出现「签约已超时」警告，状态将变为已失效。
- 规则快照（利率、还款方式、罚息、结清费率）签约后锁定，产品后续修改不影响本笔。

### 6. 还款与结清（U05）

借款放款后，在申请详情点「还款」或列表里的「还款」按钮。

**普通还款**
1. 页面自动定位**最早到期的一期**。
2. 显示本金 + 利息 + 罚息 = 本期应还额。
3. 点「确认还款本期」→ 二次确认 → 成功。

- **没有部分金额输入框**（本期不支持任意部分还款）。
- 还款成功后自动刷新计划、账户余额与流水，并产生「还款成功」消息。

**提前结清（整笔）**
1. 点「获取结清报价」→ 分列未还本金、到期利息/罚息、当期日息、结清费、减免利息。
2. 点「确认整笔结清」→ 二次确认总额。
3. 若期间金额变化，返回 409 并提示重新获取报价，**不会按旧报价扣款**。

- 未到期的利息记为「减免」，不收取。
- 结清后申请状态变「已结清」，授信占用释放。
- 余额不足时提示，不会部分扣款。

**结果未知处理**：出现「请求结果未知」横幅时，先点「刷新」核对结果；确认未成功后再重试（系统沿用同一幂等键，不会重复扣款）。

### 7. 账户（U06）

「我的账户」分四个独立指标展示：

| 指标 | 含义 |
| --- | --- |
| 账户余额 | 模拟现金，放款入账、还款出账 |
| 授信额度 | 管理员可调整，默认 50000.00 |
| 已占用授信 | 已放款未结清的**未还本金**（利息罚息不占额度） |
| 可用额度 | `max(0, 授信 − 占用)` |

下方流水表显示方向、金额、记账后余额、业务编号与时间。

### 8. 消息（U07）

「站内消息」展示审批结果、签约、放款、还款、逾期提醒。
- 顶栏消息红点为未读数，每 30 秒刷新（页面隐藏时暂停）。
- 点「标为已读」或「本页全部标为已读」。
- 同一事件只生成一条消息。

## 二、管理端

入口：登录页右下角「管理员入口」，或直接访问 `/admin/login`。
演示账号 `admin / admin123`。

> 管理端与借款人端会话**互相隔离**：借款人登录态不能进入 `/admin/*`，管理端令牌也不能当借款人用。

### 1. 用户与黑名单（U09）

**用户管理**
- 搜索框支持账号 / 手机号 / 昵称。
- 表格展示授信、已占用、可用额度、冻结与黑名单状态。
- **冻结/解冻**：二次确认，提示「冻结后无法登录、续期、申请或放款；既有债务继续计罚息，不清除欠款」。
- **调额**：输入新授信额度，提示当前占用；低于占用时被拒绝。

**黑名单**（标签页）
- 点「拉黑」，**原因必填**，确认后该用户不能新申请、不能被放款。
- 点「移出黑名单」恢复。
- 黑名单只阻断新业务，既有债务仍可查询与偿还。

### 2. 产品管理（U10）

- 列表展示每个产品的区间、固定费率、还款方式与上下架。
- 「新建产品」/「编辑」：每产品只能选一种还款方式；金额与期限上下限校验；年利率按百分数填写（`12.0000` = 12%）。
- 「下架」后不能新增申请，已提交申请不受影响。
- 页面提示：产品变更**不影响已有申请快照**。

### 3. 审批与放款（U11）

1. 顶部按状态筛选（待审核 / 待签约 / 待放款 / 已放款 …）。
2. 点「处理」打开右侧抽屉，查看申请快照与申请人。
3. **审批**：
   - 「通过」→ 二次确认 → 状态变待签约，并生成 72 小时签约截止。
   - 「拒绝」→ 必须先填原因 → 确认后状态变已拒绝。
4. **放款**：仅「待放款」出现「确认放款」，二次确认金额与申请编号。
   - 服务端会再次校验额度、冻结、黑名单；不足时返回 409/403，页面刷新真实状态，**不会在客户端标记成功**。

### 4. 逾期与统计（U12）

- 顶部四张卡片：放款总额、待还总额、逾期率（显示分子分母）、用户数、统计时刻。
- 下方逾期明细：借款人、申请编号、期次、到期日、逾期天数、未还本金/利息/罚息。
- **逾期是还款计划状态，不是申请状态**：申请仍显示「已放款」（P1 统计功能，未测试数据为空属正常）。

## 三、常见异常与对应表现

| 场景 | 页面表现 |
| --- | --- |
| 未登录访问业务页 | 跳转登录页，登录后回到原页面 |
| 会话过期 | 自动尝试续期一次；失败则清凭证回登录页并提示「登录状态已过期」 |
| 无权限（403） | 提示「没有权限执行该操作（账号可能已冻结）」 |
| 状态冲突（409） | 提示后自动刷新真实状态 |
| 金额变化（AMOUNT_CHANGED） | 清空旧报价，要求重新获取 |
| 余额/额度不足 | 明确提示，不做部分记账 |
| 网络超时 | 提示「结果待确认」，保留原幂等键，引导先查询 |
| 列表为空 | 显示空状态文案与引导按钮 |
| 加载失败 | 显示错误结果页与「重新加载」按钮 |
