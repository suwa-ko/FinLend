# 借贷软件平台（综合设计 1 项目）

> 面向高校「综合设计 1」课程的借贷软件平台项目文档仓库。
> 本文档仓库只做**可行性论证、需求分析与技术方案**，不包含代码实现；代码仓库可在此基础上另行初始化。

## 项目定位

一个**基础的借贷软件平台**：用户注册后在线申请借款，系统进行审批，审批通过后放款，用户按还款计划偿还本金与利息；管理员在后台管理用户、贷款产品、审批流程与逾期催收。系统以「业务流程跑通 + 关键业务规则正确（利息计算、审批、还款）」为核心目标，适合作为课程设计/毕设的完整闭环项目。

## 核心业务规则（速览）

- **借款流程**：注册 → 实名认证 → 提交借款申请 → 管理员审批 → 签约 → 放款 → 按期还款 → 结清。
- **利息计算**：支持「等额本息 / 等额本金 / 先息后本」三种还款方式。
- **逾期规则**：逾期产生罚息（日罚息 = 应还本金 × 罚息日利率 × 逾期天数）。
- **额度规则**：本期授信额度采用固定默认值；信用评估与动态额度为综设2预留（接口已预留）。

## 推荐技术栈（详见 01 文档）

- **后端**：Python 3.11+ + FastAPI + SQLAlchemy 2.x + Pydantic v2 + PyJWT + Redis
- **前端**：Vue 3 + Vite + Element Plus + Pinia + Axios
- **数据库**：MySQL 8.0 + Redis
- **工程管理**：pip/uv + Git

## 建议开发里程碑

1. **M1**：项目脚手架 + 数据库建表 + 用户注册/登录（JWT）。
2. **M2**：贷款产品管理 + 借款申请 + 审批流程。
3. **M3**：放款 + 还款计划生成 + 还款/逾期处理。
4. **M4**：后台管理看板 + 消息通知 + 联调与演示材料。
