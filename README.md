# 借贷软件平台（综合设计 1 项目）

> 面向高校「综合设计 1」课程的借贷软件平台项目文档仓库。
> 本文档仓库只做**可行性论证、需求分析与技术方案**，不包含代码实现；代码仓库可在此基础上另行初始化。

## 项目定位

一个**基础的借贷软件平台**：用户可通过 Web 用户端或本学期交付的安卓 App 注册、申请借款、查看还款计划并还款；系统进行审批和模拟放款，管理员在 Web 后台管理用户、贷款产品、审批流程与逾期催收。系统以「业务流程跑通 + 关键业务规则正确（利息计算、审批、还款）」为核心目标，适合作为课程设计/毕设的完整闭环项目。

## 核心业务规则（速览）

- **借款流程**：注册 → 实名认证 → 提交借款申请 → 管理员审批 → 签约 → 放款 → 按期还款 → 结清。
- **利息计算**：支持「等额本息 / 等额本金 / 先息后本」三种还款方式。
- **逾期规则**：按日计提罚息（日罚息 = 当日计费前的逾期未还本金 × 罚息日利率 ÷ 100，分日舍入；任务漏跑可补算、重跑不重计）；逾期是还款计划状态，不是申请状态。
- **还款规则**：一次普通还款结清最早到期的整期债务；本期**不支持任意部分还款**，提前还款仅支持**整笔结清**（未到期利息记为减免 `waived_interest`）。
- **额度规则**：可用额度 = max(0, 授信额度 − 已放款未结清计划的未还本金)；授信≠账户余额。默认授信 50000.00，管理员可调；信用评估与动态额度仍为后续阶段预留（接口已预留）。
- **会话规则**：access token 2 小时、refresh token 每次轮换，会话固定 7 天；Web 与 App 会话独立。
- **幂等规则**：提交/审批/签约/放款/还款等写接口携带 `Idempotency-Key`，同键同内容返回原结果、不同内容返回 409。

## 推荐技术栈（详见 01 文档）

- **后端**：Python 3.11+ + FastAPI + SQLAlchemy 2.x + Pydantic v2 + PyJWT + Redis
- **Web 前端**：Vue 3 + Vite + Element Plus + Pinia + Vue Router + Axios
- **安卓端**：uni-app（Vue 3）+ uni-ui + Pinia + `uni.request`；HBuilderX 打包签名 APK
- **数据库**：MySQL 8.0 + Redis
- **工程管理**：pip/uv + Git

## 建议开发里程碑

1. **M1**：项目脚手架 + 数据库建表 + 用户注册/登录（JWT），完成 uni-app 安卓端骨架和接口联调。
2. **M2**：贷款产品管理 + 借款申请 + 审批流程，完成安卓端登录、产品浏览和申请页面。
3. **M3**：放款 + 还款计划生成 + 还款/逾期处理，完成安卓端借款详情、还款和消息页面。
4. **M4**：后台管理看板 + 消息通知 + 安卓 APK 打包验收 + 联调与演示材料。
