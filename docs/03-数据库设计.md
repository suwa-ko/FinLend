# 03 · 数据库设计（需求分析配套）

> 本文档是功能需求分析的落地补充，给出核心表结构与关键计算说明，供后续建表与开发直接使用。

## 1. 设计约定

- 字符集：`utf8mb4`；排序规则：`utf8mb4_general_ci`。
- 金额字段：`DECIMAL(18,2)`；利率字段：`DECIMAL(8,4)`（存百分比数值，如 7.2 表示 7.2%）。
- 所有表含公共字段：`id`（自增主键）、`create_time`、`update_time`。
- 逻辑删除（可选）：`deleted TINYINT DEFAULT 0`。

## 2. ER 关系概览

```
user(用户) 1───N loan_application(借款申请) N───1 loan_product(贷款产品)
user 1───N repayment_plan(还款计划) N───1 loan_application
repayment_plan 1───N repayment_record(还款记录)
user 1───N bank_card(银行卡)
user 1───1 account(账户)
user 1───N account_flow(账户流水)
user 1───N message(消息)
user 1───1 blacklist(黑名单)
admin(管理员) ──审批── loan_application(记录 audit_opinion / audit_time)
```

> 说明：审批日志不单独建表，由 `t_loan_application` 的 `audit_opinion` / `audit_time` 字段承载；如需记录完整审批轨迹，可后续拆分为独立表。

## 4. 关键业务计算与 SQL 说明

### 4.1 生成还款计划（放款时，服务端计算）

放款时按「金额 + 期限 + 利率 + 还款方式」一次性生成 `n` 期还款计划，公式见《02-功能需求分析》§6.1。金额计算全程用 Python `decimal.Decimal`，四舍五入规则：每期金额保留两位小数，最后一期做差额平账，保证「各期本金合计 = 借款本金」。

### 4.2 逾期检测（定时任务，每日执行）

```sql
UPDATE t_repayment_plan
SET status = 3
WHERE status = 0
  AND due_date < CURDATE();
```

随后按「应还本金 × 罚息日利率 × 逾期天数」计算罚息累加到 `penalty` 字段。（更新用户信用分：综设2预留）

> 说明：上述 SQL 为简化示例，仅覆盖「未还（status=0）」的逾期标记；实际实现中「部分还（status=1）」到期同样应标记为逾期，并按未还金额计罚息，即条件应为 `status IN (0,1)`。

### 4.3 放款扣减额度（防超扣，事务内）

```
BEGIN;
  SELECT balance, version FROM t_account WHERE user_id = ? FOR UPDATE;  -- 或乐观锁
  校验余额/额度充足；
  UPDATE t_account SET balance = balance - amount, version = version + 1 WHERE id = ? AND version = ?;
  INSERT INTO t_account_flow ...;
  UPDATE t_loan_application SET status = 3, lend_time = NOW() WHERE id = ?;
  INSERT INTO t_repayment_plan ...;
COMMIT;
```

### 4.4 常用查询示例

- 用户待还总额：`SELECT SUM(principal + interest + penalty - paid_principal - paid_interest) FROM t_repayment_plan WHERE user_id = ? AND status IN (0,1,3);`
- 逾期率统计：`逾期借款数 / 总借款数`。
- 管理端分页：使用 SQLAlchemy 的 `limit`/`offset` 分页。

## 6. 建库脚本（示例）

```sql
CREATE DATABASE IF NOT EXISTS loan_platform
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_general_ci;

CREATE TABLE t_user (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  username VARCHAR(50) NOT NULL UNIQUE,
  password VARCHAR(100) NOT NULL,
  phone VARCHAR(20) NOT NULL UNIQUE,
  real_name VARCHAR(50),
  id_card VARCHAR(18),
  nickname VARCHAR(50),
  email VARCHAR(100),
  occupation VARCHAR(50),
  monthly_income DECIMAL(12,2) DEFAULT 0,
  address VARCHAR(200),
  -- 以下三字段为信用评估预留（综设2使用），本期用默认值
  credit_score INT DEFAULT 60,
  credit_level CHAR(1) DEFAULT 'C',
  credit_line DECIMAL(18,2) DEFAULT 0,
  is_real_name TINYINT DEFAULT 0,
  status TINYINT DEFAULT 0,
  last_login_time DATETIME,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB COMMENT='用户表';
```
